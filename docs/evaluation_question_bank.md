# HuskyAdvisor Evaluation Question Bank

## Purpose

This document provides a starter set of test questions for evaluating HuskyAdvisor's recommendation quality. Each question is paired with a short note about what a strong answer should generally include.

## Questions

### 1. Boeing-focused CSSE elective question

**Prompt:**  
I'm a junior CSSE student at UW Bothell and I want to work at Boeing. Which 400-level electives should I take?

**Strong answer should include:**  
Systems, embedded, testing, or hardware-adjacent courses such as CSS 430, CSS 422, CSS 427, CSS 458, or EE 450, with reasoning tied to aerospace or reliable software work.

### 2. Cloud-oriented student question

**Prompt:**  
I'm interested in cloud and backend engineering. Which UWB electives would best prepare me?

**Strong answer should include:**  
Courses such as CSS 436, CSS 432, CSS 475, and possibly CSS 430, with explanations tied to cloud, distributed systems, and backend preparation.

### 3. AI-interested student question

**Prompt:**  
I'm interested in AI and machine learning. What courses should I look at after CSS 342?

**Strong answer should include:**  
Courses such as CSS 382, CSS 440, CSS 486, or CSS 487, and mention that mathematical and algorithmic preparation matters.

### 4. Applied Computing pathway question

**Prompt:**  
I'm deciding between CSSE and Applied Computing. I like practical software and business-oriented problem solving. Which path seems stronger?

**Strong answer should include:**  
Applied Computing as a serious option, with courses like BIS 315, BIS 360, BIS 340, CSS 436, and an explanation of flexibility versus engineering depth.

### 5. Embedded systems question

**Prompt:**  
I want to work on embedded systems or robotics. What classes should I prioritize?

**Strong answer should include:**  
EE 271, EE 331, EE 450, CSS 422, and CSS 427, with explanation of hardware-software integration.

### 6. Internship readiness question

**Prompt:**  
What should I focus on over the next few quarters if I want to be internship-ready by next summer?

**Strong answer should include:**  
A quarter-based plan involving coursework, projects, documentation, teamwork, and portfolio building.

### 7. Networking career question

**Prompt:**  
What courses would help if I want to work in networking or telecom?

**Strong answer should include:**  
CSS 432, CSS 431, CSS 430, possibly CSS 337 or security-related courses, and mention companies like T-Mobile or AT&T Bothell.

### 8. Product/web career question

**Prompt:**  
I'm more interested in product development and web applications than low-level systems. What should I take?

**Strong answer should include:**  
CSS 481, CSS 474, CSS 480, CSS 478, BIS-related applied courses, and product-oriented reasoning.

### 9. Security pathway question

**Prompt:**  
Which UWB courses help prepare for cybersecurity or secure software roles?

**Strong answer should include:**  
CSS 310, CSS 337, CSS 457, and explanations around defensive systems, risk, and secure design.

### 10. Local company alignment question

**Prompt:**  
Which local companies around Bothell or Redmond fit a student interested in software engineering and AI?

**Strong answer should include:**  
Microsoft Redmond, Google Kirkland, Amazon Bellevue, and tie them to backend, cloud, or AI-aligned coursework.

## Suggested Evaluation Rubric

- **Relevant:** Does the answer actually match the student's goal?
- **Grounded:** Does it use UWB-style course information rather than generic advice?
- **Actionable:** Does it tell the student what to do next?
- **Honest:** Does it avoid pretending to know live internships or official advising decisions?
