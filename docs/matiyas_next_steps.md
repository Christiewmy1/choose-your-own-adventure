# Matiyas Next Steps

## Purpose

This document defines the most reasonable remaining tasks for the data/documentation/evaluation role now that much of the HuskyAdvisor planning layer is already in place.

## Best Remaining Tasks

### 1. Strengthen Major Comparison Support

- expand or refine the major comparison dataset
- make sure CSSE, Applied Computing, and EE differences are easy to explain
- support slides and demo explanation with concrete examples

### 2. Improve Source Transparency

- add more source URLs to important course records
- separate clearly official schedule-derived information from curated inference

### 3. Keep Demo And Evaluation Honest

- update evaluation notes when recommendation behavior changes
- check that the website and slides do not overclaim live internship features

### 4. Support Presentation Quality

- keep the slide language aligned with the actual MVP
- help make sure “what is built” and “what is future scope” stay clear

## What This Means In Plain English

The biggest remaining value of the Matiyas role is not to invent more features. It is to make the current features:

- more believable
- easier to explain
- better grounded in real UWB data
- easier to test during the demo
