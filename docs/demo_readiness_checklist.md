# HuskyAdvisor Demo Readiness Checklist

## Purpose

This checklist is for the team to confirm the project is truly demo-ready before presenting.

## Website

- [ ] Landing page loads locally
- [ ] Profile form loads
- [ ] Results page renders without placeholder INFO/BUS content
- [ ] Website clearly says UWB or UW Bothell
- [ ] Error state is understandable if backend is not running

## Backend

- [ ] API starts locally
- [ ] `/health` responds correctly
- [ ] profile recommendations endpoint works
- [ ] company alignment endpoint works
- [ ] internship prep endpoint works
- [ ] roadmap endpoint works

## Advising Quality

- [ ] Completed courses are not recommended again
- [ ] Company suggestions look believable
- [ ] Internship prep output includes remaining next steps
- [ ] Roadmap output looks tied to the student profile

## Data Credibility

- [ ] Course records and organized course groups exist for the currently supported UWB majors
- [ ] Source notes exist for important course records
- [ ] Official schedule snapshot is present
- [ ] Multi-quarter schedule snapshot is present

## Presentation Readiness

- [ ] Team can explain what HuskyAdvisor is in one sentence
- [ ] Team can explain what is built vs future scope
- [ ] One persona-based example is ready for live demo
- [ ] Slides match the actual project status
