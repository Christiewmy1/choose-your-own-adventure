# HuskyAdvisor Website Testing Checklist

## Purpose

This checklist is for testing the website MVP once the frontend is running. It focuses on whether the site behaves like HuskyAdvisor, not just whether it loads.

## Basic Access

- [ ] Landing page loads
- [ ] Main project explanation is visible
- [ ] Start button works
- [ ] Navigation does not break

## Profile Flow

- [ ] User can enter a major
- [ ] User can enter class standing
- [ ] User can enter completed courses
- [ ] User can enter career goals
- [ ] Validation appears if required fields are missing

## Recommendation Results

- [ ] Results page appears after profile submission
- [ ] At least 3 recommendations are shown
- [ ] Recommendations look UWB-relevant
- [ ] “Why” explanations are visible
- [ ] Prerequisite or caution text is visible

## Company Alignment

- [ ] Company suggestions appear
- [ ] Suggested companies are regional and believable
- [ ] The page explains that this is alignment, not live job data

## Internship Prep

- [ ] Prep guidance appears in a readable format
- [ ] Courses, projects, and skills are all shown
- [ ] The page makes clear that this is planning support, not a live internship board

## Content Quality

- [ ] The site clearly says UW Bothell or UWB
- [ ] The language matches HuskyAdvisor rather than filler text
- [ ] There are no obvious unrelated placeholder course examples
- [ ] The project copy matches the proposal scope

## MVP Acceptance Checks

- [ ] A student can understand the purpose within 30 seconds
- [ ] A student can submit a profile and get useful results
- [ ] The site supports the project story: majors, courses, company alignment, and internship prep

## Notes

Use this section during testing to record bugs, unclear outputs, or mismatches between backend logic and frontend presentation.
